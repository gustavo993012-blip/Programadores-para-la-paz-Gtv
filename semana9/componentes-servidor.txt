Sistema operativo:
Es la base que administra el hardware y permite ejecutar servicios como Node.js.
Controla recursos, procesos y permisos para que el servidor funcione de forma ordenada.

Node.js:
Es el entorno que ejecuta JavaScript fuera del navegador.
Permite correr aplicaciones como server.js y atender solicitudes HTTP.

Aplicación server.js:
Es el archivo que define las rutas y la lógica del servidor.
En este caso responde en / y /estado con información simple.

Puerto:
Es el punto de acceso por donde el servidor recibe solicitudes.
Aquí se usa el puerto 3000 para probar la aplicación localmente.

Logs:
Son registros de eventos, mensajes y errores del servidor.
Sirven para monitorear la ejecución y detectar problemas.
