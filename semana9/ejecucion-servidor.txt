Al ejecutar node server.js, Node.js inicia la aplicación y Express deja disponible el servidor en el puerto 3000.
En la terminal aparece el mensaje: Servidor ejecutándose en puerto 3000.
Cuando se visita la ruta /estado, el servidor responde con un objeto JSON que confirma que el servicio está funcionando.

Ejemplo de respuesta:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
