AUTOMATIZACIÓN CON N8N Y TELEGRAM - SEMANA 10
==============================================

FLUJO DE AUTOMATIZACIÓN: NOTIFICACIÓN DE NUEVAS INCIDENCIAS
===========================================================

1. ¿QUÉ EVENTO ACTIVA EL FLUJO?

   Evento: Cuando se registra una nueva incidencia en la base de datos del sistema
   
   Trigger Technical: Un webhook HTTP POST enviado desde la aplicación web o un polling
   que verifica periódicamente (cada 5 minutos) si hay nuevas incidencias sin procesar.


2. ¿QUÉ MENSAJE SE ENVIARÍA A TELEGRAM?

   Formato de Mensaje:

   "🚨 NUEVA INCIDENCIA REPORTADA
   
   📍 Zona: [Zona reportada]
   🏷️ Categoría: [Tipo de incidencia]
   📝 Descripción: [Primeras 150 caracteres]
   
   ⏰ Hora: [Hora del reporte]
   🔗 Revisar en: [Link al sistema]
   
   #Reporte #Comunitario"


3. ¿QUÉ INFORMACIÓN NO DEBERÍA ENVIARSE POR SEGURIDAD?

   ❌ DATOS QUE NO SE ENVIARAN A TELEGRAM:

   - Nombre completo del reportante: Usar solo un alias o ID anónimo
   - Documento de identidad (cédula, pasaporte): Nunca incluir números de identificación
   - Dirección exacta del domicilio del reportante: No incluir dirección personal completa
   - Teléfono personal o WhatsApp: Datos de contacto directo del ciudadano
   - Contraseñas o claves: Nunca enviar credenciales de ningún tipo
   - Información de ubicación GPS exacta del reportante: Solo zona general si es posible
   - Fotos con información sensible: Asegurar que no contengan placas, rostros reconocibles, etc.
   - Datos de contacto de testigos: Proteger privacidad de otros ciudadanos
   - Información médica o personal sensitiva mencionada en el reporte
   - Números de cuenta bancaria o datos financieros


RESUMEN DEL FLUJO EN N8N
=========================

1. TRIGGER: Webhook recibe POST con datos de nueva incidencia
2. DATABASE: Verificar que sea incidencia no notificada
3. FORMAT: Construir mensaje seguro para Telegram
4. SANITIZE: Remover información sensible
5. SEND: Enviar mensaje a Telegram
6. LOG: Registrar que la notificación fue enviada
7. ERROR: En caso de fallo, guardar en cola de reintentos

Ventajas de este flujo:
- Coordinadores informados en tiempo real
- Proceso automatizado (sin intervención manual)
- Datos protegidos por seguridad
- Registro de auditoría de notificaciones
